How it works

  1. Set up the learner list and subjects once.
  2. Each teacher chooses their subject and enters marks, then saves.
  3. Or upload several photo, Excel, Word, or PDF files at once; check the detected marks and confirm the import.

  5. For different devices, use Move / back up data to transfer updates. Automatic live sharing requires a connected online database; this standalone app does not sync devices by itself.

Import multiple assessment files

Upload multiple Excel workbooks, Word documents (.docx), PDFs, or images containing assessment tables. Each file or worksheet becomes a separate import sheet. Add any missing assessment slots under Enter Marks first, then assign each sheet to the correct assessment and class before applying. Excel is the most reliable format; Word tables are extracted, PDFs use text/table-position extraction, and images use OCR. Always review the preview/mapping and correct any extracted headings or marks before importing. Existing marks are merged by default; blank incoming cells do not erase saved marks.

Assign workbook sheets to saved assessment slots

The app scans worksheet names and the first rows for titles such as Assessment 1, Mid-Term Exam or End-Term Test, then suggests the matching assessment slot. Always verify the suggested destination before importing. Every worksheet from every uploaded workbook can be assigned to any saved assessment slot. This also works with a workbook containing only one sheet. The app identifies learner and subject columns by their header names, so their left-to-right order can differ between worksheets. Upload several separate workbooks at once, or upload a workbook with many sheets. For a single-sheet workbook, simply choose where that sheet should be saved.

Legacy three-slot mapping

Use “Do not import” for assessment slots not included in this workbook. The first rows are scanned for column headings. Make sure each sheet has learner name or admission number plus subject columns.

File readers may need an internet connection the first time. Excel is most reliable; verify Word/PDF/OCR extraction before importing.

Workbook preparation tips

  • Use a clear header row with columns such as Admission No, Learner Name, ENG, KISW, MATHS, etc.
  • Worksheets can have different names; assign them to the appropriate assessment above.
  • Marks should be numeric values from 0 to 100. Empty cells remain blank.
  • Importing merges by default so learner details and other assessments are preserved. Export a backup before choosing replace.

Learner report access

This section explains how learners can access their reports. The current app keeps records only in the browser where staff enter them; a learner using another phone cannot log in to this copy and see those records automatically.

For a real learner portal, the school needs an online database and secure sign-in (for example, admission/UPI/assessment number plus a private PIN or password). Names or admission numbers alone are not secure because other people may know them.

Until secure accounts are connected, share individual reports with parents using the SMS, WhatsApp or email buttons in the Report Card tab. Protect student results and share only with the verified parent/guardian.

Share this application

Share the app with another teacher or school. The method depends on how you opened it:

If this app is hosted on a website, copy its URL or use the device share menu. Anyone with access to that link can open the app.

If you opened this app from a downloaded HTML file, it does not have a public internet link yet. Send the original School Report Card App HTML file as an email or WhatsApp attachment, or upload it to a trusted web host first.

When sharing the app file, share a blank/template copy where possible. Your learner records are saved in this browser, but are not included automatically in the app file. Use Backup / Restore separately to transfer records, and only share learner data with authorized staff.

Important privacy note

This standalone app saves data locally in the browser on the device where it is used. Sharing a link or HTML app file does not create shared online storage or synchronize learner records between devices. Protect backups because they may contain confidential learner information.
